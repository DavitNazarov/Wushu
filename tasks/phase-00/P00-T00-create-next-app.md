# P00.T00 — Create Next.js app (App Router)

## Goal
Initialize the project in the current repo using npm.

## Steps
1. Run: `npm create next-app@latest .`
2. In prompts choose: TypeScript=Yes, ESLint=Yes, Tailwind=Yes, src/=Yes, App Router=Yes, import alias=@/*.
3. Run: `npm run dev` and confirm it loads.

## Acceptance
- [ ] App runs locally without errors
- [ ] Project uses TypeScript, Tailwind, App Router, and `src/`
- [ ] No extra features added yet
