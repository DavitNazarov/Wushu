# P00.T04 — UI primitives

## Goal
Create small reusable UI components (no business logic).

## Steps
1. Install: `npm i clsx`
2. Create `src/components/ui/Button.tsx` (primary/secondary/ghost)
3. Create `src/components/ui/Card.tsx`
4. Create `src/components/ui/Badge.tsx`
5. Use these components on `src/app/[locale]/page.tsx` as a demo

## Acceptance
- [ ] Components are typed and reusable
- [ ] Home page uses primitives
- [ ] No file exceeds ~250 lines
