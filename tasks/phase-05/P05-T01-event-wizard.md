# P05.T01 — Event creation wizard

## Goal
Create event with dates, categories, enabled weights, optional platforms.

## Steps
1. Wizard steps: Details → Age groups → Weights enable → Platforms
2. Auto-fill round time from age group template; allow override
3. Enable/disable weight templates per gender+age group
4. Allow 0..N platforms

## Acceptance
- [ ] Event created
- [ ] Categories created
- [ ] Platforms optional
- [ ] Overrides saved
